For a separate consistent DB snapshot use Configuration → Backup first, or check the box below to include one in this apply's backup directory.

Alternative: stage the update via SSH instead of the upload box above. 
scp -r aerodrome/ user@server:/opt/aerodrome/update/
# or
rsync -av aerodrome/ user@server:/opt/aerodrome/update/
Either path lands in /opt/aerodrome/update/ (or wherever your install lives — replace /opt/aerodrome with your install dir if you used --prefix). The new release will be applied with the current config.yaml, database, logs, and venv preserved. The previous install is backed up to .backups/<timestamp>/.
