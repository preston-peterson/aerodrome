Slow-query diagnostic

Captures slow queries from instrumented endpoints into an in-memory ring buffer so you can see what hung the page without having to SSH into the box and grep journalctl. Currently instrumented: /api/aircraft/{icao}, /api/all/drill, /api/stats. Threshold is 500 ms; faster queries aren't recorded.

Query-plan checks
Runs EXPLAIN QUERY PLAN against your actual database with the ICAO that has the most sightings as the parameter (worst-case for planner mis-pick). All three run automatically when this page loads, sequentially, in the same order they fire when you click an aircraft in production: detail_recent_sightings (from /api/aircraft/{icao}) first, then drill_select and drill_count (from /api/all/drill). First query pays cold-cache cost; the next two see warm cache — same as a real page load. Use "Re-run" to refresh any single check; "Re-run all" goes through the same sequence.
Connection tuning audit
Each endpoint either uses the tuned connection helper (cache, mmap, temp_store applied per your profile) or opens a default connection. Untuned endpoints get the SQLite defaults regardless of your Configuration → Database profile choice.
